# 単語の追加

`data/words.json`(単語オブジェクトの配列)に単語を追記する。

## 形式

```json
{
  "hanzi": "你好",
  "pinyin": "nǐ hǎo",
  "meaning": "こんにちは",
  "unit": "基礎1",
  "examples": [
    { "zh": "你好，我叫小明。", "pinyin": "Nǐ hǎo, wǒ jiào Xiǎomíng.", "ja": "こんにちは、私はシャオミンといいます。" }
  ]
}
```

## 手順

1. 先に `data/words.json` を読み、同じ `hanzi` が既にあれば新規追加せず、意味や例文をその項目に追記・修正する。
2. ユーザーが渡した情報(漢字、意味、Duolingoのユニット名、例文)を使う。足りない項目は補う。
   - `hanzi` は簡体字。
   - `pinyin` は声調記号つき(nǐ hǎo)。数字表記(ni3)にしない。
   - `meaning` は日本語。
   - `unit` はユーザーが言ったときだけ入れる。不明なら省略する。
   - 例文が指定されていなければ、Duolingoの初級レベルに合う短い例文を1〜2個作る。例文は `zh` / `pinyin` / `ja` の3点セットにする。
3. 配列の末尾に追加する。インデントは2スペースで、JSONとして正しいことを `python3 -m json.tool data/words.json > /dev/null` で確認する。
4. 追加した単語を一覧で簡潔に報告する。ピンインや意味に自信がない箇所は、そう伝える。
5. コミットする。メッセージは `Add words: 你好, 谢谢` のようにする。pushやPR作成は、ユーザーが頼んだとき、または開発ブランチの運用に従って行う。
